# KG Play School website prototype

Open `index.html` in a modern browser. The site is a self-contained static website with no build step.

## Included

- Responsive public school website
- Mobile navigation
- Single-school visit and admissions journey
- Accessible Playgroup and Nursery programme tabs
- Admissions form validation and WhatsApp enquiry handoff
- Reduced-motion support
- Locally stored, optimized WebP imagery

## Deployment

The included `vercel.json` configures the site for Vercel. Import the repository as a new Vercel project and deploy with the default settings; no build command is required.

## Content checks

- Replace the sample parent story with an approved, consented testimonial.
- Replace the placeholder policy links with approved privacy, terms and accessibility pages.
- Verify facilities, programme details and school imagery before a public campaign.
